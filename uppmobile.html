UPPMobile RegionIT — Privacy Policy

Last updated: November 26, 2026 · English / Русский

EnglishРусский

1. About the application

UPPMobile RegionIT is a business application for connecting to a compatible 1C:Enterprise UPP (Manufacturing Enterprise Management) server configured by the user or their organization. It provides order and specification views, inventory information, item images and warehouse transfers. This policy describes the mobile application; the organization operating the server is responsible for its own processing.

2. Data processed

The app processes the server address, username and password, order numbers, item codes and names, scanned barcode values, warehouse identifiers, stock dates, quantities, transfer comments and records, and information and images returned by the server. Responses may contain personal information depending on the organization’s database. These data are used to authenticate users, retrieve information and perform requested warehouse operations.

3. Network communication and security

Requests are sent to the configured 1C server using its HTTP API. Credentials are included in authentication headers and request data. HTTPS protects data in transit when correctly configured; plain HTTP does not encrypt traffic. Use HTTPS with a valid certificate, especially outside trusted networks. The app uses iOS Keychain for password storage and standard platform security mechanisms. No system is entirely risk-free.

4. Server operators and sharing

The app sends operational requests and credentials to the configured server. Its operator controls access, server-side records, logs, retention and any further sharing. The app does not provide a separate developer-operated backend in the reviewed implementation. Organizations should authorize access and inform users about their own data handling.

5. Analytics and advertising

The reviewed application contains no dedicated advertising, tracking or third-party analytics SDK. The configured server may maintain access and operational logs. The developer may receive information voluntarily supplied in support correspondence.

6. Device permissions

Camera access is used to scan barcodes and QR codes. Camera frames are processed on the device by the iOS scanner; the scanned value may be used in a server request. Local network access is used to communicate with a configured server on the local network. Permissions can be changed in iOS Settings.

7. Retention and deletion

The server address and username are stored in iOS application preferences, and the password is stored in Keychain. Operational results are held in application state; system network caching may apply. Users can replace or clear connection settings. Uninstalling removes application data subject to iOS and backup behavior; Keychain entries may persist. For server-side records, access or deletion requests, contact the organization operating the server. Business records may be retained as required by applicable rules.

8. Children and international processing

The application is intended for business use and is not directed to children. Data may be processed in the country where the configured server and its operator’s systems are located.

9. Changes and contact

This policy may be updated when the application or its data handling changes. For questions about the app or this policy, email kuznecov4555@gmail.com. For server-side data and account management, contact your organization or server administrator.

UPPMobile RegionIT — Политика конфиденциальности

Обновлено: 26 ноября 2026 года

1. О приложении

UPPMobile RegionIT — бизнес-приложение для подключения к совместимому серверу 1С:Предприятие УПП (Управление производственным предприятием), настроенному пользователем или его организацией. Приложение позволяет просматривать заказы и спецификации, складские остатки, изображения номенклатуры и создавать складские перемещения. Политика описывает работу мобильного приложения; организация, управляющая сервером, отвечает за собственную обработку данных.

2. Обрабатываемые данные

Приложение обрабатывает адрес сервера, логин и пароль, номера заказов, коды и наименования номенклатуры, значения отсканированных штрихкодов, идентификаторы складов, даты остатков, количества, комментарии и сведения о перемещениях, а также информацию и изображения, полученные от сервера. Ответы могут содержать персональные данные в зависимости от базы организации. Данные используются для авторизации, получения информации и выполнения запрошенных складских операций.

3. Передача данных и безопасность

Запросы направляются на настроенный сервер 1С через его HTTP API. Учётные данные передаются в заголовках авторизации и теле запросов. При корректной настройке HTTPS защищает данные при передаче; обычный HTTP не шифрует трафик. Рекомендуется использовать HTTPS с действительным сертификатом, особенно вне доверенной сети. Пароль хранится в iOS Keychain. Используются стандартные механизмы безопасности iOS. Абсолютная безопасность не гарантируется.

4. Операторы серверов и передача третьим лицам

Приложение направляет рабочие запросы и учётные данные на настроенный сервер. Его оператор управляет доступом, серверными записями, журналами, сроками хранения и дальнейшей передачей данных. В проверенной реализации отдельный сервер разработчика не предусмотрен. Организация должна предоставлять доступ уполномоченным пользователям и информировать их о собственной обработке данных.

5. Аналитика и реклама

В проверенной реализации приложения отсутствуют отдельные рекламные SDK, средства отслеживания и сторонние SDK аналитики. Настроенный сервер может вести журналы доступа и операций. Разработчик может получать сведения, добровольно предоставленные при обращении в поддержку.

6. Разрешения устройства

Камера используется для сканирования штрихкодов и QR-кодов. Кадры обрабатываются на устройстве средствами сканирования iOS; распознанное значение может использоваться в запросе к серверу. Доступ к локальной сети используется для подключения к настроенному серверу в локальной сети. Разрешениями можно управлять в настройках iOS.

7. Хранение и удаление данных

Адрес сервера и логин хранятся в настройках приложения iOS, пароль — в Keychain. Результаты операций хранятся в состоянии приложения; возможно системное сетевое кэширование. Пользователь может изменить или очистить параметры подключения. При удалении приложения его данные удаляются с учётом особенностей iOS и резервных копий; записи Keychain могут сохраниться. По вопросам доступа к серверным данным и их удаления обращайтесь к организации, управляющей сервером. Хозяйственные документы могут храниться в соответствии с применимыми требованиями.

8. Дети и международная обработка

Приложение предназначено для делового использования и не ориентировано на детей. Данные могут обрабатываться в стране размещения настроенного сервера и систем его оператора.

9. Изменения и контакты

Политика может обновляться при изменении функций приложения или порядка обработки данных. По вопросам приложения и политики обращайтесь по адресу kuznecov4555@gmail.com. По вопросам серверных данных и управления учётными записями обращайтесь к своей организации или администратору сервера.
